# Nombre_rationnel

Exercice en langage C : manipulation de nombres rationnels et de fractions, écrit sans bibliothèque
externe.

## Contenu

- `Nombre_rationnel.h` et `Nombre_rationnel.c` : structure de nombre rationnel et opérations
- `main.c` : programme de démonstration
- `Nombre_rationnel.cbp` : projet Code::Blocks

## Compiler

```bash
gcc main.c Nombre_rationnel.c -o nombre_rationnel
./nombre_rationnel
```

## Contexte

Exercice d'école (2019), premier travail sur les structures et l'arithmétique en C.
